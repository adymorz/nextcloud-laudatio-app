# Security policy

Laudatio stores personal data of people who usually have no Nextcloud account, so security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue. Send a description of the problem, the affected version and the steps to reproduce it to **dev@adrian.dymorz.ch**. You get an answer within a few days.

Once the problem is fixed, a new release is published and the fix is mentioned in the [changelog](CHANGELOG.md). You are credited there if you wish.

## Supported versions

Only the latest release in the [Nextcloud App Store](https://apps.nextcloud.com/apps/laudatio) receives fixes. Keep Nextcloud and the app up to date.
